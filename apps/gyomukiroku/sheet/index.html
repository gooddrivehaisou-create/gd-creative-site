声の業務記録 ・ 管理者向け

会社のスプレッドシートにつなぐ

ドライバーが記録すると、会社のGoogleスプレッドシートに1日1行で自動で入ります。パソコンで、上から順に進めてください（15分ほど・無料）。

1

スプレッドシートを作る

Googleドライブで新しいスプレッドシートを作り、名前を「業務記録」などにします。会社のGoogleアカウントで作ると、後で引き継ぎが楽です。

2

プログラムを貼る

  1. スプレッドシートの上のメニューで 拡張機能 → Apps Script を開く
  2. 最初から入っている文字を全部消す
  3. 下の「プログラムをコピー」を押して、そのまま貼りつける
読み込んでいます…
3

会社コードを決めて書きかえる

貼ったプログラムの上の方にある const COMPANY_CODE = 'ここに会社コード'; の「ここに会社コード」を、自分で決めた合言葉に書きかえます（例：gd-2026-kiroku）。書きかえたら保存（Ctrl+S）。

この会社コードを、ドライバーにアプリの「設定」で入れてもらいます。知らない人に書き込まれないための合言葉なので、外に出さないでください。

4

ウェブアプリとして公開する

  1. 右上の デプロイ → 新しいデプロイ
  2. 歯車マーク → ウェブアプリ を選ぶ
  3. 次のユーザーとして実行：自分 ／ アクセスできるユーザー：全員
  4. デプロイ を押し、Googleアカウントの承認画面で許可する
    「このアプリはGoogleで確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」で進めます。自分で作ったプログラムなので問題ありません。
  5. 表示された ウェブアプリのURL（https://script.google.com/macros/s/…/exec）をコピーする

確認：そのURLをブラウザで開いて "ok":true と "codeSet":true が出れば準備できています。

5

URLを伝える

コピーしたURLを、アプリの管理担当（Claude）に送ってください。アプリにつないで反映します。
自分で入れる場合は、サイトの apps/config.js の GD_SHEET.url に貼ります。

6

ドライバーに会社コードを伝える

アプリの 設定 →「会社コード」に入れて保存してもらいます。「今日」の画面に 会社のスプレッドシートに送信済み と出れば完了です。

それまでにスマホに残っていた記録も、まとめて送られます。圏外で記録した分は、電波が戻った後の次の記録の時に送られます。

プログラムを後から書きかえた時は、デプロイ → デプロイを管理 → 鉛筆マーク → バージョン「新バージョン」→ デプロイ、で更新してください（URLは変わりません）。
