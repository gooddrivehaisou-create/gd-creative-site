声の業務記録 ・ 管理者向け

会社のスプレッドシートにつなぐ

ドライバーが記録すると、会社のGoogleスプレッドシートに1日1行で自動で入ります。スマホでもパソコンでもできます。上から順に進めてください（15〜20分・無料）。

1

このページを「2つ」開いておく

このページは、プログラムをコピーするのに使います。もう1つのタブで、次の手順のGoogleの画面を開きます。

スマホなら、Safari（iPhone）かChrome（Android）で進めてください。LINEの中のブラウザだとうまくいきません。

2

Apps Script を開く

  1. 新しいタブで script.google.com（新しいプロジェクト） を開き、Googleアカウントでログイン
  2. スマホの場合：画面が崩れたり「アプリを使ってください」と出たら、パソコン用の表示に切り替えます
    • iPhone（Safari）：アドレス欄の左の ぁあ →「デスクトップ用Webサイトを表示」
    • Android（Chrome）：右上の ︙ →「PC版サイト」にチェック
  3. 「無題のプロジェクト」の編集画面が開けばOK（開かない時は「新しいプロジェクト」を押す）

文字が小さい時は、2本指で広げて拡大してください。

3

プログラムを貼る

  1. このページに戻って「プログラムをコピー」を押す
  2. Apps Scriptのタブに戻り、最初から入っている function myFunction() {…} の文字を全部消す
    スマホ：文字を長押し →「すべてを選択」→ 削除
  3. 同じ場所を長押し →「ペースト」
読み込んでいます…
4

会社コードを書きかえて保存

貼った文の上の方（19行目あたり）の const COMPANY_CODE = 'ここに会社コード'; の「ここに会社コード」だけを消して、自分で決めた合言葉を入れます（例：gd2026kiroku。英数字がおすすめ）。' '（クォート）は消さないでください。

上のフロッピーディスクのマーク（保存）を押します。

この会社コードを、あとでドライバーのアプリにも入れてもらいます。ドライバー以外には教えないでください。

5

ウェブアプリとして公開する

  1. 右上の青い デプロイ →「新しいデプロイ」
  2. 「種類の選択」の歯車マーク → ウェブアプリ
  3. 「次のユーザーとして実行」：自分 ／「アクセスできるユーザー」：全員
  4. デプロイ →「アクセスを承認」→ 自分のGoogleアカウントを選ぶ
  5. 「Googleはこのアプリを検証していません」と出たら：左下の 詳細 →「（プロジェクト名）（安全ではないページ）に移動」→ 許可
    自分で作ったプログラムなので問題ありません。
  6. 「ウェブアプリ」の下のURL（https://script.google.com/macros/s/…/exec）の コピー を押す
6

URLを開いて確かめる → 私に送る

  1. コピーしたURLを、新しいタブで開く
  2. "ok":true と "codeSet":true が出ればOK。このとき、Googleドライブ（スプレッドシートのアプリ）に 「業務記録（声の業務記録）」 が自動でできます
  3. そのURLを、Claudeとの会話に貼って送ってください。アプリにつないで反映します

"codeSet":false の時は、4の会社コードが書きかわっていません。書きかえて保存し、下の「プログラムを後から書きかえた時」の方法で更新してください。

7

ドライバーに会社コードを伝える

アプリの 設定 →「会社コード」に入れて保存してもらいます。「今日」の画面に 会社のスプレッドシートに送信済み と出れば完了です。

それまでスマホに残っていた記録も、まとめて送られます。圏外で記録した分は、電波が戻った時に送られます。

プログラムを後から書きかえた時は、デプロイ → デプロイを管理 → 鉛筆マーク → バージョン「新バージョン」→ デプロイ、で更新してください（URLは変わりません）。
